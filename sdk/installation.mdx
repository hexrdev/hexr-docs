`hexr-sdk` is published on **public PyPI**. You do not need a Hexr account,
a licence key or a private index to install it or to use the decorators.

```bash
pip install 'hexr-sdk[cli]'
```

<Note>
`pypi.hexr.cloud` is the private mirror deployed agent pods install from. You do
not need it, or any `--extra-index-url`, to install the SDK.
</Note>

## Requirements

| | |
|---|---|
| Python | 3.11, 3.12 or 3.13 |
| Platform | macOS (Apple Silicon and Intel), Linux x86_64, Linux aarch64 |
| Anything else | Nothing. No cluster and no cloud account to install or analyse |

<Warning>
macOS and ARM Linux wheels ship from **0.5.31**. On 0.5.30 and earlier
`pip install hexr-sdk` failed on macOS (no wheel, so pip tried to compile
the Rust analyzer) and on ARM Linux (a `psutil` pin with no aarch64
wheel). If you hit either, upgrade: `pip install -U hexr-sdk`.
</Warning>

## With uv

```bash
uv pip install 'hexr-sdk[cli]'
```

## Why there is a `[cli]` extra

The default install is the **lean agent-pod profile**: it has one runtime
dependency, because it is what ships inside your agent containers and
those should not carry command-line tooling.

Everything you need to instrument an agent is in the base install:

```python
from hexr import hexr_agent, hexr_tool, hexr_llm
```

The `[cli]` extra adds `click` and `rich`, which the `hexr` command needs.
If you install the base package and run `hexr`, it tells you so rather
than failing with a traceback:

```
hexr: the CLI needs the optional `cli` extra, which is not installed.

    pip install 'hexr-sdk[cli]'
```

## Other extras

| Extra | Adds |
|---|---|
| `cli` | The `hexr` command (`click`, `rich`) |
| `aws`, `gcp`, `azure` | Cloud SDKs for credential exchange on that provider |
| `observability` | OpenTelemetry exporters |
| `frameworks` | Common agent frameworks, for local experimentation |
| `enterprise` | The L3 signature-suggestion model (ONNX weights) |
| `all` | Everything above |

Install several at once:

```bash
pip install 'hexr-sdk[cli,aws,observability]'
```

## Verify

```bash
python -c "import hexr; print(hexr.__version__)"
hexr --help
```
